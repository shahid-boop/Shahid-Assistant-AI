## Development status

This repository is being initialized for the Shahid Assistant project. The initial commit establishes project guidance and an OpenCode multi-agent workspace. Application implementation will be added in subsequent work.

## Safety principles

- Preserve existing files, features, configuration, workflows, and Git history.
- Do not run destructive commands or overwrite user data.
- Keep secrets and API keys out of source control.
- Review changes and run available checks before reporting completion.
